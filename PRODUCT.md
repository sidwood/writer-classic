# Product context

The user requests an exact reimplementation of iA Writer Classic with Tauri and Vue.js, working on Apple Silicon, with Vim and dark mode added. All repository work belongs in the goal checkout. This is a desktop writing tool, not a modern library/sidebar product.

The installed iA Writer Classic 2.1.6 is the behavioral and visual authority. Product assumptions are derived from that app's bundled help and screenshots, not from a new-design interview. The brief pins the visual world, so there is no new visual-direction selection.

The user later specified default-on Vim, persistent explicit off, all three visual selection modes with working operators, a checked Vim toggle in Edit, and a centered native document title with a Markdown proxy icon. Traffic lights remain in the native title bar; no second in-window header is allowed. The icon owner supplies original assets separately.

The primary task is composing and revising local plain-text Markdown without distracting chrome. Files and unnamed drafts must survive save failure, cancellation and application restart. Exact Classic parity is the target, not an inferred completion claim.
