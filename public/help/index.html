Writer Classic Help

A plain-text Markdown writing window. This help book is original to this app. It is not the iA Writer Classic manual.

Documents Focus Editing Scripting

Documents

File ▸ New opens another window. Open, Save, and Save As keep the text exactly as typed, including blank lines and Unicode. Named documents autosave. Close asks before discarding unsaved changes.

Quick Look can preview Markdown and plain-text files with the generator installed in this app.

Focus and appearance

Focus Mode dims and blurs every sentence except the one at the caret. That sentence stays sharp and full contrast. The rest of the editor is not blurred as a whole. View ▸ Dark Mode switches the paper and type colors.

Editing

Edit ▸ Delete removes the selection. With no selection, it deletes the next character. Substitutions ▸ Smart Copy/Paste inserts or removes a space so a pasted or deleted word does not run into its neighbors. Smart Links underlines URLs. Data Detection underlines dates, phone numbers, and addresses. Command-click a detection to follow it.

Window ▸ Bring All to Front orders this app’s windows in front of other apps without changing their order.

Vim Mode, when checked in the Edit menu, uses Vim motions. Command shortcuts stay on the Command key so Control chords remain available to Vim.

AppleScript

The front document’s text can be read and replaced, and a file can be opened: 

tell application "Writer Classic"
  get text of front document
  set text of front document to "Hello"
  open POSIX file "/Users/me/Notes.md"
end tell
